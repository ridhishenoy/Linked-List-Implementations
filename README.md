# Linked List Implementations in Java

This repository contains implementations of three types of linked lists in Java.

## 1. Singly Linked List
- Insert at beginning, end, and a specified position
- Delete from beginning, end, and a specified position
- Display the list
- Search for an element
- Reverse the list
- Check size and whether the list is empty

## 2. Doubly Linked List
- Insert and delete nodes at different positions
- Display the list in forward and reverse order
- Search for an element
- Reverse the list
- Check size and whether the list is empty

## 3. Circular Linked List
- Insert and delete nodes at different positions
- Display the circular list
- Search for an element
- Reverse the list
- Check size and whether the list is empty

## Language
Java
